# Релиз «Наш Хамон»

Состояние проекта и путь боевого запуска. Этот файл — часть репозитория: обновляется при каждом изменении релизного состояния. Секреты сюда не пишутся.

## Два артефакта

| Артефакт | Где живёт | Назначение | Статус |
|---|---|---|---|
| Демо-витрина | https://ssrjkk.github.io/our-jamon/ | показ заказчику и трафику до запуска магазина; заказы не отправляются (баннер «Демо-витрина») | 🟢 релиз-кандидат: все гейты зелёные |
| Движок магазина | `shop/` (Next.js 16) | боевой магазин: корзина, Т-Банк, 1С, админка, согласие 152-ФЗ | 🟡 код готов, ждёт хостинг и боевые ключи |

## Гейты качества (запускать перед каждым релизом)

```
cd shop
npm run typecheck        # типы
npm test                 # unit: контракт каталога, подпись Т-Банка, SQLite, деплой-гейты, арт карточек
npm run build            # сборка движка
npx playwright test      # e2e: обе витрины, 3 вьюпорта, axe, путь покупателя
```

Зелёный набор: typecheck, unit 179/179, e2e 289/289 (74 skipped — вьюпортно-условные).

## Путь боевого запуска

### Шаг 0. Что должно прийти от Виталия (блокеры)

1. **Хостинг**: аккаунт Vercel или VPS с Docker — выбор за заказчиком
2. **Реквизиты ИНН/ОГРНИП** — в футер обеих витрин (сейчас заглушек нет: блок заполнится при получении)
3. **Боевые ключи Т-Банка**: терминал и пароль эквайринга (подключены к расчётному счёту)
4. **Доступ к 1С:УНФ**: URL выгрузки каталога и токен (или решение работать на вшитом прайсе 0711)
5. **Розничные цены**: прайс поставщика или наценка лавки (27 позиций сейчас «уточняются»)
6. **Порог бесплатной доставки** и допуск взвешивания (±15 г) — цифры в env одной правкой
7. Фото/видео: макро-видео нарезки для первого экрана, фото кусков и ног (сейчас — ярлыки выдержки), разрешение на фото поставщика либо свои съёмки

### Шаг 1. Переменные окружения

Полный список с комментариями — `shop/.env.example`. Минимальный боевой набор:

```
SHOP_URL=https://<домен>            # боевой адрес, из него собираются sitemap/robots/canonical
# SHOP_MODE не задавать или задать live: пустое значение — уже боевой режим
ADMIN_PASSWORD=<минимум 16 символов>  # без него админка выключена
TBANK_TERMINAL_KEY=<терминал>
TBANK_PASSWORD=<пароль эквайринга>
ONEC_API_URL=<адрес выгрузки 1С>    # необязательно: без него витрина на прайсе 0711
ONEC_TOKEN=<токен 1С>
FREE_DELIVERY_FROM=<порог, ₽>
DELIVERY_CDEK_RUB=<тариф> DELIVERY_YANDEX_RUB=<тариф> DELIVERY_DRIVEE_RUB=<тариф>
ORDERS_DB_PATH=/data/orders.sqlite  # путь на постоянном диске
```

Демо-защита: `SHOP_MODE=demo` превращает магазин в витрину с демо-оплатой. Забытая переменная не может случайно сделать боевой магазин демо — demo включается только явным словом.

### Шаг 2а. Деплой на Vercel

```
cd shop
npx vercel login
npx vercel --prod
# в Dashboard → Settings → Environment Variables внести набор из шага 1
# sqlite на serverless не живёт: выбрать VPS, либо внешний Postgres (интерфейс orders допускает замену)
```

### Шаг 2б. Деплой на VPS (Docker)

```
scp -r shop/ vps:/srv/nash-hamon
cd /srv/nash-hamon && docker build -t nash-hamon .
docker run -d --name nash-hamon -p 3000:3000 \
  --env-file .env -v /srv/nash-hamon-data:/data nash-hamon
curl -s http://127.0.0.1:3000/api/health   # {"status":"ok","mode":"live",...}
```

Dockerfile несёт HEALTHCHECK по `/api/health`. Данные заказов — в томе `/data` (SQLite); бэкап — копия файла в кроне.

### Шаг 2в. Без Docker (уже проверено)

`npm run build:standalone` собирает самодостаточный пакет в `.next/standalone`; запуск `PORT=3000 SHOP_MODE=live node server.js`. На этой машине проверено: сервер поднимается, `/api/health` отвечает `{"status":"ok"}`, витрины 200.

### Шаг 3. После запуска

1. `https://<домен>/api/health` — статус и режим
2. Пробный заказ: кусок → подтверждение веса в админке (`/admin`, пароль из `ADMIN_PASSWORD`) → ссылка Т-Банка → оплата → webhook `paid`
3. Пробный фасованный заказ: оплата сразу через Init Т-Банка
4. Сверить витрины: цены на Pages-демо и движке совпадают (гейт catalog-parity держит)
5. Снять баннер «Демо-витрина» и решить судьбу демо-страницы: noindex или редирект на боевой домен

## Откат

VPS: `docker stop nash-hamon && docker run ... <предыдущий образ>`. Vercel: Promotions → откат на предыдущий deployment. SQLite-данные при откате не трогаются томом.

## Границы текущего релиза

- Автосообщения в мессенджеры (Telegram/WhatsApp/SMS) и бронирование ПВЗ СДЭК не подключены: ссылка на оплату передаётся покупателю вручную из админки
- Личный кабинет — без пароля по ссылке заказа (токен в URL); бэкенд-токен хранится в заказе
- Куски и ноги — по среднему весу с подтверждением при связи (решение Виталия), целые ноги — фиксированная цена за штуку
